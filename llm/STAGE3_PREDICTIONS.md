# Stage 3 predictions (written before any live-network call)

Generated by `llm/make_predictions.py` from `results/llm/stage2/summary_stage3.csv` (Stage 2 surrogate simulations, `llm/stage2.py`). Committed before any Stage 3 API call. Claims concern **these models at these pinned endpoints**, not LLMs in general.

## Stage 3 protocol (the surrogate simulations use exactly this)

- **Network:** N = 100 agents on a random-regular graph with degree 4. Every agent has exactly 4 contacts, inside the fitted k ≤ 6 range; ER c = 4 would put ≈ 11% of agents beyond it.
- **Ties:** each tie is rival with probability ρ, and both ends perceive it the same way (ε = 0).
- **Replication:** 5 independent graphs per point, two replicas per graph, each replica starting from an independent 50/50 random configuration.
- **Updates:** asynchronous random-sequential, 10 warm-up sweeps then 10 measured sweeps (2,000 updates per replica).
- **Each update is one API call** to the pinned Stage 1 endpoint, using the Stage 1 template for the point's framing (instruction v2). The prompt gives the agent's own current position and its 4 contacts, each on its own line, in random order.
  - **Per-call randomisation:** a fresh random letter mapping (which content is A) and a fresh random option order (Amendment 3d). In neutral framing the positions are relabelled per call.
  - **Decision:** sampled locally from the returned first-token logprobs at T = 1, renormalised over {A, B}. A call with leak > 5% is repeated once; if it leaks again, the agent keeps its position (logged).
- **Measures** are identical to `llm/surrogate.py`, time-averaged over the 10 measured sweeps:
  - |m| and signed m (+ = position P);
  - persistence: overlap with the agent's own configuration at the end of warm-up;
  - flip rate;
  - excess unsatisfied ties: the fraction of directed ties that are unsatisfied, minus the frustration floor for the same graph family and ρ (0 at ρ = 0; 0.146–0.153 at ρ ≥ 0.25);
  - replica overlap |q|.

## Pre-stated evaluation

For each point, compute the observed mean over the 5 graphs of each measure (replicas averaged within each graph).
- **Surrogate passes a measure** if the observed mean lies inside the fitted surrogate's 90% mean-of-5 interval.
- **The point is discriminating** if the observed primary measures fall outside the control intervals the surrogate is meant to beat:
  - P1, P2, P4: both primary measures outside both the Ising-reading and the fields-only intervals.
  - P3: |m| outside both control intervals; persistence outside the Ising interval (the fields-only control predicts the same freezing, so persistence cannot separate it).
- **Overall:** the surrogate is supported if it passes both primary measures at ≥ 3 of P1–P4. The naive Ising reading is rejected at a point if its interval excludes the observed primary measure. P5 is a calibration and does not count toward the verdict.
- **Operating characteristic of this rule:** if the surrogate were exactly right and the two primary measures independent, each lies inside its 90% interval with probability 0.9. Both pass at a point with ≈ 0.81, and ≥ 3 of 4 points pass with ≈ 0.83. A correct surrogate is therefore declared 'not supported' ≈ 17% of the time.
- **Reporting:** all measures are reported at every point, whatever the outcome. No re-fitting and no change of points after seeing Stage 3 data.

## Caveats

- **Finite-time, finite-size predictions:** N = 100, 20 sweeps. The long-run behaviour is in `results/llm/stage2/summary_fss.csv`.
  - In neutral framing, Qwen-122B keeps order up to N = 1600 at ρ ≤ 0.25, and Llama-70B coarsens slowly (unclear).
  - Political and workplace 'order' is field-driven: there is a content field, so it is not a phase transition.
- **The surrogates are fitted on single-shot prompts.** Stage 3 tests whether the network dynamics follow from the single-shot response function; any memory or history effects in live agents are what Stage 3 can reveal.
- **These four points use only confirmatory endpoints** (they passed both the comprehension check and the noise gate). The Gemma endpoints await the local bf16 replication (Amendment 4).
- **ER c = 4 predictions are in the summary file as secondary.** At Stage 3 scale they differ from the random-regular ones by ≤ 0.16 in |m|.
- **Cost:** P1–P4 total ≈ $3.46 at Stage 1 per-call cost (≈ $5 with a 50% margin). P5 is a sampling endpoint (one sampled reply per update) and adds ≈ $0.40.
